This week's exposure action
Monday Morning Prompt

"What is the one thing I could do this week that cannot be completed alone, cannot be checked off a list, and would put my name in front of someone who matters?"

Name the action. Then run it through the three filters below before it counts.

Three qualifier filters — action must pass all three
Requires another person
Not solo execution. This only happens if someone else is involved.
Leaves no task residue
Can't be marked done in Notion or Asana. No checkbox will close this.
Builds surface area
Someone above or lateral to you becomes aware you exist in a new context.
All three pass. This action belongs on your week. Put it first — before you touch your system.
Fails one or more filters. This is a task, not an exposure action. Put it back in your system where it belongs.
How to use this
  • 1 Every Monday morning, before you open your task manager, answer the prompt above. Name one action.
  • 2 Run it through the three filters. If it fails any filter, it goes back in the system. Find a different action.
  • 3 That action happens first this week — before any system maintenance, inbox processing, or dashboard updates.
  • 4 Log it below. At the end of the week, mark whether it happened. Five weeks of this changes what leadership sees.
Weekly Log
