# The Executive Lens — a Claude skill

A 5-minute diagnostic that scores how leadership actually sees you, names your biggest visibility gap, and hands you one move to make Monday. It runs inside Claude, against your real situation — not a generic quiz.

## Install (60 seconds)

This is a Claude Code skill. To install it:

1. Unzip this folder.
2. Move the `executive-lens` folder into your Claude skills directory:
   - **macOS / Linux:** `~/.claude/skills/executive-lens/`
   - **Windows:** `%USERPROFILE%\.claude\skills\executive-lens\`
3. Open Claude Code and type `/executive-lens` — or just say *"run the Executive Lens on me."*

That's it. Claude walks you through 15 questions, scores you across the five dimensions, and tells you which gap to close first.

No account, no email, no upload. It runs locally inside your Claude.

## Don't use Claude Code yet?

You can still run it: open the `SKILL.md` file, copy the whole thing into any Claude chat, and say *"act as this skill and run the assessment on me."* Same result.

## What you'll get

- A score across 5 dimensions of executive visibility (out of 75)
- Your tier — from "Who's Behind the Mask" to "In the Game"
- Your single biggest gap, named, with why it's costing you
- One specific thing to do before your next meeting
