# The Executive Visibility Playbook — a Claude skill

The full 30-day system for going from invisible to in-the-conversation — as a guided program, not a document. It scores your five visibility signals, diagnoses where you stand, then runs a day-by-day sequence that adapts to your two weakest signals and writes the actual communications using your real material.

## What's inside
One skill, three parts that work as a program:
1. **The Visibility Gap Audit** — 5 signals scored to /25, a diagnosis, and the Mirror Exercise that names your real gap.
2. **The 30-Day Orchestrator** — one action per day (most under 5 minutes), tuned to your two lowest signals, with weekly checkpoints and a maintenance cadence after Day 20.
3. **12 Executive-Communication Templates** — runnable plays the program dispatches on the right day: status translator, incident-as-risk, ownership email, breadcrumb update, strategic question, champion brief, and more. You bring rough material; it returns the finished email.

The difference from a PDF of prompts: this *runs* the system. When a day says "send a breadcrumb update," it asks what you did and writes it.

## Install (about 60 seconds)

**If you use Claude Code:**
1. Unzip this folder.
2. Drop the `executive-visibility-playbook` folder into `~/.claude/skills/`.
3. Restart Claude Code. Say *"start the visibility program"* — or, returning, *"I'm on day 9"* — and it runs.

**If you use Claude in the browser or any chat:**
1. Open `SKILL.md`, paste it into a new chat, say *"Act as this skill."*
2. Say *"start the program"* and answer the audit honestly.

## How to use it
Start with the audit — answer honestly, even when it's unflattering; the diagnosis only works if it's real. Then run a day at a time. You don't have to do it in one sitting; come back and say which day you're on. When a day produces a communication, hand over your real, messy notes and let it write the finished version, then do one pass so it sounds like you.

This pairs with the free **Visibility Toolkit** skill — that's the base set of checks; this is the full orchestrated system on top of it.
