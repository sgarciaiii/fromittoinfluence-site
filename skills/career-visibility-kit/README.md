# The Career Visibility Kit — a Claude skill

Six AI plays for the exact moments most technical people go quiet. This isn't a set of copy-paste prompts you fill in by hand — it's an installable skill that asks for your real material and writes the finished thing in your voice.

## What's inside
One skill, six plays:
1. **Executive Status Update** — the update leadership actually reads
2. **Performance Review Narrative** — your self-assessment at the level above you
3. **Project Positioning Memo** — get seen as the one driving the project
4. **LinkedIn Visibility Post** — sounds like a practitioner, not a content creator
5. **Meeting Follow-up That Builds Credit** — the official record, written by you
6. **Champion Brief** — arm your sponsor to advocate for you accurately

## Install (about 60 seconds)

**If you use Claude Code:**
1. Unzip this folder.
2. Drop the `career-visibility-kit` folder into `~/.claude/skills/`.
3. Restart Claude Code. Type the skill name (or just say *"I owe leadership a status update"*) and it runs.

**If you use Claude in the browser or any chat:**
1. Open `SKILL.md`.
2. Paste it into a new Claude chat and say *"Act as this skill."*
3. Tell it which moment you're in.

## How to use it
Don't fill anything in. Tell it the moment ("it's review season," "I just left a big meeting"), answer the few questions it asks with your real, messy notes, and it hands you the finished draft. Then do one edit pass so it sounds like you.
